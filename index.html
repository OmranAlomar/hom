كيف أحصل على المفتاح مجاناً؟
  1. افتح Google Cloud Console وأنشئ مشروعاً جديداً.
  2. من «APIs & Services» ثم «Library» ابحث عن YouTube Data API v3 وفعّلها.
  3. من «Credentials» اختر «Create credentials» ثم «API key» وانسخ المفتاح هنا.
  4. يُفضّل تقييد المفتاح بهذا الـ API فقط. الحصة المجانية تكفي آلاف المقاطع يومياً.

بدون مفتاح تُجلب القوائم من خوادم Invidious المفتوحة، وقد تتوقف أو تتأخر. المفتاح يُحفظ في متصفحك فقط. القوائم الخاصة (Private) لا يمكن جلبها، ويجب أن تكون عامة أو غير مدرجة.
